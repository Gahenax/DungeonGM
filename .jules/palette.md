## 2024-06-20 - Converting structural DIVs to semantic Buttons
**Learning:** Found an accessibility issue where the CharacterSheet header was an interactive structural `div` with an `onClick` handler. Converting it to a `<button>` provides native focusability and keyboard navigation, but requires careful application of CSS resets (`background: none`, `border: none`, `color: inherit`, `font-family: inherit`, `width: 100%`, `text-align: left`, etc.) to maintain the existing visual layout, along with adding `:focus-visible` outlines.
**Action:** When implementing interactive elements like clickable headers, always use a semantic `<button>` element with `aria-expanded` and `aria-controls` properties for screen reader accessibility and reset its styles to match the application's design system.
