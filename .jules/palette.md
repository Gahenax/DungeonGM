## 2024-07-08 - Semantic Button Replacements
**Learning:** For frontend accessibility, interactive elements like clickable headers or custom buttons currently using `div` with `onClick` handlers must be converted to proper semantic HTML elements (e.g., `<button>`) with keyboard handling and focus styles. When doing this conversion, CSS reset properties (like `background: none`, `border: none`, `color: inherit`, `font-family: inherit`, `width: 100%`, and `text-align: left`) are essential to maintain the existing layout and appearance before adding `:focus-visible` outlines.
**Action:** Always convert interactive `div`s to semantic tags like `<button>` and accompany them with the necessary CSS resets to preserve the original visual structure while gaining native accessibility benefits.
