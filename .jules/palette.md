## 2024-05-18 - Semantic Tags and ARIA
**Learning:** React components acting as custom interactive elements (like the CharacterSheet header) often use `div` with an `onClick` handler, missing keyboard navigation and focus states. Changing them to semantic `<button>` tags requires adding CSS reset properties to maintain existing visuals. Also, dynamic chat feeds need `role="log"` and `aria-live="polite"` for screen readers.
**Action:** Always check custom interactive elements for semantic tag usage. If `div` must be converted to `button`, add CSS resets (`background: none`, `border: none`, `color: inherit`, `width: 100%`, `text-align: left`). Add `role="log"` and `aria-live="polite"` to narrative chat containers. Ensure form inputs missing visible `<label>` have `aria-label`.
