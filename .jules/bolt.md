## 2025-07-07 - Add Database Indexes for Temporal Queries
**Learning:** In the SQLite database wrapper, methods like `get_campaign` and `get_character` frequently use `ORDER BY created_at DESC LIMIT 1` to find the latest active entry. Without a database index on the `created_at` column, this causes O(n) full table scans as the dataset grows, degrading backend performance. Also, when benchmarking asynchronous SQLite drivers like `aiosqlite`, all async database methods (including `initialize` and `close`) must be properly awaited to prevent `RuntimeWarning` exceptions and ensure accurate measurements.
**Action:** When manually writing SQLite table creation statements, always explicitly include `CREATE INDEX IF NOT EXISTS` for temporal or frequently queried columns (e.g., `created_at`). When modifying test or benchmark scripts interacting with an async database wrapper, always verify that `await` is used correctly on async methods.
