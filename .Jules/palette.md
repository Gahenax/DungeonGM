## 2024-07-06 - Structural A11y and Semantic Buttons
**Learning:** In dynamic game interfaces, it is critical to use `role="log"` and `aria-live="polite"` on chat containers to ensure screen readers automatically announce narrative updates. Also, custom structural components like `div` headers used as interactables (e.g. CharacterSheet header) need to be converted to semantic `<button>` tags with proper ARIA attributes (`aria-expanded`) and CSS reset properties (`background: none; border: none; text-align: left;`, etc.) along with `:focus-visible` styles to ensure keyboard accessibility while preserving layout. In addition, when form elements lack visible text labels due to limited space, they must be augmented with `aria-label`s.
**Action:** Always add ARIA live regions for chat logs, apply semantic button patterns to interactive elements along with reset styles, and provide missing form labels.
